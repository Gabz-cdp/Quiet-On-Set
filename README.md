# Quiet-On-Set
3D First person exploration game.

READ_ME
 
On Sunday one of our group member's GitHub and Unity stopped working, making them unable to connect to the group Repo or access any unity files. This meant that one group member was unable to access anything related to the project from Sunday until after submission. The interaction mechanic that this group member was intending to do was therefore done by the other two group members during late Sunday and Monday. However, the interaction mechanic is failing to function correctly. This mechanic exists in the ObjectInteraction script. As a temporary solution for this first iteration, another attempt at an interaction mechanic was made using the base of the picking up mechanic that was given to us in class, which exists in the Item, PlayerInteraction and PlayerPickup scripts. This also is not working in it's current state. After many hours of trying to fix these issues and with time running out we have made the decision to leave the game as is and accept the penalties from only having one functioning non-basic mechanic, being the Camera/Hidden Object Mechanic. All the aspects of the non-functioning mechanics, however, have been left in the game. This includes text, unused InteractableObjects, and the previously mentioned scripts. We assure that these issues will be resolved by the second prototype submission.
